GAME HUB — QUICK PUBLISH

1. Open your GitHub repository.
2. Click Add file → Upload files.
3. Extract this ZIP on your computer first, then drag index.html, style.css, wheelie.html, wheelie.js, music.html, and README.txt into the upload area. You can upload the images folder too if you later add your own images.
4. Click Commit changes.
5. Open Settings → Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select Branch: main and Folder: / (root), then click Save.
8. Wait a few minutes. Your website address is https://YOURUSERNAME.github.io

This site links to third-party game websites and includes an original simple wheelie mini-game and a local-file music player. It does not bypass school network restrictions. Game availability depends on the website and network rules.
